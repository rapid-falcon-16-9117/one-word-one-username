A tiny Python program that writes our own make.fun username — rapid-falcon-16-9117 — as one word to entry.txt for the "One Word, One Username, One Reward" bounty. The judge picks the funnier or more interesting username, and a genuine handle beats any invented word, so the entry is exactly our handle: 20 characters, one word, no gloss.

## Run it

```sh
python3 main.py
```
